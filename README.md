Para executar o código, basta executar o main.py, e especificar o caminho relativo para o arquivo de texto contendo as expressões em RPN logo em seguida da chamada do main.

exemplo:
C:/Users/User/AppData/Local/Programs/Python/Python312/python.exe "c:/code/analisador-lexico/codes/main.py" analisador-lexico\txt\exemplo1.txt

Assim, o Main executaria, utilizando os dados presentes no arquivo "exemplo1.txt"e geraria os códigos assembly no arquivo "exemplo1.s".

Para executar o código assembly, o seguinte site deve ser acessado: https://cpulator.01xz.net/?sys=arm-de1soc , e o conteúdo do arquivo "exemplo1.s" deve ser colado no campo central do site, substituindo quaisquer textos que já estivessem preenchidos por padrão, em seguida podendo prosseguir com eventuais verificações de execução do assembly.
